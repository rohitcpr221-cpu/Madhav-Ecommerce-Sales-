# Madhav-Ecommerce-Sales-
Analysed the data of a online ecommerce store across India . In this dataset we have two sub dataset named Orders and Details which contain features like customer name, order id ,order date , payment mode and many more.
In this project i have analyzed : a) Sum of amount by state.
                                  b)Customer by purchasing amount.
                                  c)Average profit by Month.
                                  d)Quantity by category.
